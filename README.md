# Автоматизированные UI тесты сайта dantist8.ru

## Описание
Автоматизированные UI тесты сайта https://dantist8.ru/

Проверяются основные элементы интерфейса сайта.

Инструкция по запуску автотестов
Установка зависимостей
pip install -r requirements.txt
Установка браузеров Playwright
playwright install
Запуск тестов

Каждый тест запускается отдельно:

Главная страница
python test_main_page.py
Меню сайта
python test_menu.py
Контакты
python test_contacts.py
Формы
python test_forms.py
Общая информация
Все тесты написаны на Python + Playwright
Каждый файл тестирует отдельный функциональный блок сайта
Тесты можно запускать независимо друг от друга
Вспомогательные функции вынесены в utils.py

## Что тестируется
- Главная страница
- Меню
- Контакты
- Формы (без отправки данных)
